OMOS (codename **Sirius**) is an operating system written from scratch in Rust. Its long-term goal is to make the
computers you own act as one private system. Today it's an **early developer preview**: the kernel, memory
management, multicore scheduling, message-passing IPC, capability handles and a first set of user-space drivers.

<Warning>
    **What exists today:** OMOS boots on **x86_64** (UEFI) in a virtual machine, starts its built-in drivers and
    services, and shows a status screen and a serial log. There's **no shell, no apps, no networking and no installer**
    yet, and ARM64 and RISC-V run only in QEMU's `virt` machine during development. Everything beyond that is on the
    [roadmap](/omos/roadmap).
</Warning>

## At a glance

| | Today |
| --- | --- |
| **Kernel** | Rust, `no_std`; hybrid design — core hardware support in the kernel, storage and input drivers in user space |
| **Boot** | UEFI only, via the Limine bootloader, with kernel address randomization (KASLR) |
| **Architectures** | x86_64 developer preview; ARM64 and RISC-V in QEMU `virt` only |
| **Programs** | Six built-in services and drivers; no way to start your own programs yet |
| **Storage** | Read-only boot archive, plus a FAT32 disk on a virtio block device |
| **Networking** | None |
| **Version** | 1.0.0 "Sirius" (developer preview) |

## Who it's for right now

People curious about operating-system internals who want to boot an independent kernel in a virtual machine and
follow its progress. It isn't something to install on a computer you use.

## Licensing

OMOS is proprietary and closed-source. The compiled system is free for personal, education, non-profit and smaller
commercial use — see [Licensing](/omos/licensing).
