<AccordionGroup>
    <Accordion title="Do I need an account or an app?">
        Neither. Sidedrop is a website — open it on both devices, pair them, and drop files.
    </Accordion>
    <Accordion title="Is there a file size limit?">
        Sidedrop sets none. In Chrome, Edge and most desktop browsers, received files stream to the browser's
        own storage, so multi-gigabyte files work while there's free disk space. Browsers that buffer in memory
        (Sidedrop warns you) can't take very large files. See [Send files, folders and text](/sidedrop/sending).
    </Accordion>
    <Accordion title="Does it only work on the same Wi-Fi?">
        No — it works across networks, for example a phone on cellular and a laptop on Wi-Fi. A few strict
        networks block direct connections; then Sidedrop connects through a relay automatically — it forwards
        the encrypted data without being able to read it. See
        [Connections & reconnects](/sidedrop/how-it-works).
    </Accordion>
    <Accordion title="Can I send to another person, not just my own devices?">
        Yes. Share your room's link or code; when they join, you're paired. Share it only with them — whoever
        joins first is connected, and there's no accept step.
    </Accordion>
    <Accordion title="Can more than two devices join?">
        No — a room connects exactly two devices.
    </Accordion>
    <Accordion title="What happens if my connection drops mid-transfer?">
        It pauses and continues from where it stopped once the connection is back — as long as both tabs stay
        open. Closing or reloading a tab ends the session.
    </Accordion>
    <Accordion title="Which browsers work best?">
        Chrome and Edge on desktop: they stream large files to disk and offer a save dialog and folder saving.
        Firefox, Safari and phones work too, saving through ordinary downloads (a zip for several files).
    </Accordion>
    <Accordion title="What does it cost?">
        Nothing. Sidedrop is free, with no ads.
    </Accordion>
    <Accordion title="Is it open source?">
        The web app is, under the MIT license. The signaling server it uses isn't part of that repository —
        see [Run from source](/sidedrop/run-from-source).
    </Accordion>
</AccordionGroup>
