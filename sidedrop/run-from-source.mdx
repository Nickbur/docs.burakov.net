The Sidedrop **web app** — everything that runs in your browser — is open source under the **MIT
license**. To pair two devices it needs a **signaling server**, which introduces the browsers and can hand
out relay credentials.

<Warning>
    The signaling server that sidedrop.burakov.net uses **isn't part of the open-source repository**, and it
    only accepts connections from Sidedrop's own sites. So you can run, read and change the web app; to pair
    devices with your own build, you need a signaling server of your own that speaks the same protocol.
</Warning>

## What you need

- **Node.js 24.16 or newer** — the project refuses to install on older versions.
- A **signaling server** that speaks Sidedrop's protocol, for pairing to work.

## Run it locally

<Steps>
    <Step title="Get the code">
        ```bash
        git clone https://github.com/Nickbur/sidedrop_app.git
        cd sidedrop_app
        npm install
        ```
    </Step>
    <Step title="Point it at a signaling server">
        The app reads the server address from `VITE_API_URL` (default `http://localhost:3000`) and connects
        to its WebSocket at `/v1/signaling/ws`. `npm run switch_to_dev` copies `env/env.dev` to `.env` with
        the local default.
    </Step>
    <Step title="Start the dev server">
        ```bash
        npm run serve
        ```
        The app runs on `http://localhost:8103` (a fixed port).
    </Step>
</Steps>

<Note>
    `http://localhost` counts as a secure context, so the direct connection, browser storage and the
    clipboard all work in development without HTTPS.
</Note>

## Build

```bash
npm run build
```

This runs formatting, linting, type-checking and the unit tests, then writes the production build to
`dist/`. `npm run fix` formats the code for you.

To serve the build yourself:

- `VITE_API_URL` is baked in **at build time** — set it before building.
- Serve `dist/` as static files over **HTTPS**, with a fallback so that room links (`/r/…`) return
    `index.html`.
- The signaling server must accept your site's origin.

## Contribute

Issues and pull requests are welcome on [GitHub](https://github.com/Nickbur/sidedrop_app).

- Run `npm run build` before you open a pull request — it checks formatting and linting, type-checks and runs the
    tests. `npm run fix` formats the code.
- Commit messages follow [Conventional Commits](https://www.conventionalcommits.org/) (`type(scope): subject`); a
    commit hook checks them.
- A pre-commit hook rejects stray files, very large files and unresolved merge-conflict markers.
- Contributions are accepted under the project's **MIT license**.
