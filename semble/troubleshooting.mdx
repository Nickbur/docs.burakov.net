## Can't join

| Message | Meaning |
| --- | --- |
| *This meeting link is invalid or has ended.* | The meeting doesn't exist any more (it was deleted) or the link is wrong. |
| *This meeting is full right now.* | A free meeting allows 4 people — the host can turn Kai on to allow up to 50. Any meeting holds at most 50. |
| *The host has locked this meeting — new people can't join.* | Ask the host to unlock it. |
| *This free meeting has reached its time limit.* | Free meetings last 40 minutes. |

## You were taken out of the call

The ending screen says why — for example *The host removed you from this meeting.*, *You joined from another
tab or device.*, *The room was closed.* or *The server restarted — please rejoin.* Tap **Back to start**.

## No sound, or others can't hear me

- Look for **Tap to enable sound** — some browsers block audio until you interact with the page.
- If your microphone or camera is blocked, you join muted. Allow them for the site in your browser
    settings; **More → Audio & video** saying *No devices found. Make sure permissions are granted.* means the
    browser can't see them.
- Check the **Speaker** button isn't muting everyone for you.

## Screen sharing doesn't work

*Screen sharing is not supported in this browser.* — use a desktop browser. *Screen sharing could not be
started. Please check your browser permissions.* — allow screen recording for your browser in your system
settings.

## Kai doesn't answer

- Start with **"Kai"** (or "Hey Kai") and ask in the same breath — a pause after the name, or the name in
    the middle of a sentence, isn't picked up.
- Check the tile says *Kai is listening*. If it says Kai is off, the host needs to turn it on.
- *Not enough credits. Add credits from the home screen to enable AI.* — the host's wallet is empty.
- *The Kai session ended — re-enable it to keep asking.* — the host turns Kai on again.
- *A little too fast — try again in a moment.* — wait a moment between questions.
- Any other error — try again in a moment.
- If many people are talking at once, Kai may miss a question — ask again when it's quieter, or type it.

## Documents

*That file is too large — up to about 200,000 characters.* — split it into smaller documents. *This meeting
already has the maximum number of documents.* — the host can remove some (the limit is 50).

## Recording

*Not enough credits to record. Add credits from the home screen.* — top up first. *Recording is not
available right now. Please try again later.* — try again in a moment.

## Summary

*No transcript to summarize yet.* or *A summary is written from the transcript, which is kept only while Kai
is on.* — Kai has to be on during the meeting for there to be a transcript.

## Checkout

*Could not start checkout. Please try again.* — try again. After *Payment received — credits will appear
shortly.*, tap ↻ on the credits card.
