Divine eCommerce is an open-source **e-commerce engine** you run on your own server: a server-rendered storefront,
an admin panel, and the modular PHP framework they're built on. Everything runs in Docker — nginx, PHP-FPM,
PostgreSQL and a small background worker.

## What's inside

| Area | What you get |
| --- | --- |
| **Catalog** | Categories, brands, products with image galleries, option axes and a SKU matrix (own price, stock and image per SKU), cross-variants, specifications, faceted filters. |
| **Discovery** | Instant search suggestions and a full search page across products, categories, brands, articles and pages. |
| **Cart & checkout** | Guest checkout, one order total computed in one place, taxes, the delivery and payment methods you set up — for example store pickup or Nova Poshta, payment on delivery, or online card payment through LiqPay. |
| **Promotions** | Reward points, coupons, gift certificates, product bundles, a store-wide promo banner. |
| **Customer accounts** | Profile, addresses, orders, wishlist, compare, reviews, newsletter subscriptions, points history. |
| **Content** | Blog with "shop the story" products, info pages, a menu builder, editable contact details, a home-page slider. |
| **SEO** | Meta title and description templates, `robots.txt`, an XML sitemap, canonical links and analytics tags. |
| **Admin** | Catalog, orders and returns, reviews, promotions, newsletter campaigns, CSV import/export, staff roles with per-section permissions. |
| **Extending** | A plugin system for routes, services, event listeners, templates and database migrations, managed from the admin, plus direct access to every template. |

<Note>
    Divine eCommerce is a single-store, **single-currency (UAH)** engine, and a few admin sections store data that the
    storefront doesn't use. The [Admin tour](/divine-ecommerce/admin) marks them.
</Note>

## The stack

PHP 8.5 on a small PSR-based framework, PostgreSQL 18, Twig templates, and TypeScript built with Vite. See
[Architecture](/divine-ecommerce/architecture).
