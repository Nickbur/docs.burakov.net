---

Не знакомы с раскладкой? Сначала прочитайте [Архитектуру](/ru/shipwide/architecture). Все
переменные окружения собраны в [Конфигурации](/ru/shipwide/configuration).

## Требования

- **Node 22+** и npm.
- **Docker** (для локальных PostgreSQL + Redis) — или свои Postgres 17 / Redis 7.
- Только для нативных сборок: **Xcode 26+** (iOS), **Android SDK 36 + JDK 21** (Android), **Rust
  stable** (десктоп). Для запуска веб-приложения не нужны.

## 1. Бэкенд (`shipwide_api`) — начните отсюда

<Steps>
  <Step title="Установка и настройка">
    ```bash
    cd shipwide_api
    npm install
    npm run switch_to_dev          # env/env.dev → .env (локальные дефолты, готово как есть)
    ```
  </Step>
  <Step title="Запуск Postgres + Redis">
    ```bash
    docker compose up -d db redis  # или: docker compose up --build для всего сразу
    ```
  </Step>
  <Step title="Миграции, сид, запуск">
    ```bash
    npm run db:migrate
    npm run seed                   # тестовые/ревью-аккаунты (no-op, если TEST_ACCOUNTS пуст)
    npm run serve                  # http://localhost:3000
    ```
  </Step>
</Steps>

Проверка: `curl http://localhost:3000/v1/health`. Интерактивная справка по API:
`http://localhost:3000/docs`. Минимум env — `DATABASE_URL`, `REDIS_URL`, `JWT_SECRET`
(≥32 символов) — `env.dev` их задаёт.

<Note>
  **Почта в dev:** `EMAIL_DEV_MODE=true` печатает одноразовые коды входа в консоль API вместо
  отправки письмом, так что беспарольный вход работает без SMTP.
</Note>

## 2. Приложение (`shipwide_app`)

```bash
cd shipwide_app
npm install
cp env/.env.example .env           # затем задайте VITE_BACKEND_URL=http://localhost:3000
npm run serve                      # Ionic dev-сервер (веб) — http://localhost:8100
```

Вход: введите любой email → прочитайте 6-значный код из **консоли API** → вы внутри (неизвестный
адрес создаётся на месте). Нативно: `npm run build:native`, затем откройте проект `ios/` /
`android/` — см. [Приложение](/ru/shipwide/app).

## 3. Админ-панель (`shipwide_admin`)

```bash
cd shipwide_admin
npm install
npm run switch_to_dev              # env/env.dev → .env (указывает на :3000)
npm run serve                      # http://localhost:5174
```

Войдите с `ADMIN_LOGIN` / `ADMIN_PASSWORD`, заданными в env **API**, или по email-коду сотрудника
(печатается в консоль API). Первый админ поднимается из `ADMIN_EMAILS`. API автоматически
разрешает этот origin через `ADMIN_URL` — держите `ADMIN_URL` и порт в согласии.

## 4. Сайт (`shipwide_website`)

```bash
cd shipwide_website
npm install
npm run switch_to_dev              # env/env.dev → .env
npm run serve                      # http://localhost:4321
```

Весь контент — плейсхолдеры; см. [Сайт](/ru/shipwide/website) и
[Кастомизацию](/ru/shipwide/customization), чтобы сделать его своим.
