Полная таблица env каждой части — в её собственном разделе; эта страница — карта и подводные камни.

## Соглашения

- Каждая часть поставляет два шаблона, `env/env.dev` и `env/env.prod`; скрипт копирует выбранный в
  `.env`: `npm run switch_to_dev` / `switch_to_prod`. `.env` в gitignore.
- **`VITE_*` (приложение, админка) и `PUBLIC_*` (сайт) вшиваются в собранный бандл** — поэтому
  **переключайтесь на prod до сборки** и **никогда не кладите секрет в них** (уедет каждому
  посетителю). Они для публичных значений: URL, публичные ключи, фиче-флаги.
- **Настоящие секреты живут только в серверном окружении API** (`env.prod` на сервере) — вписанные
  в плейсхолдеры `CHANGE-ME`, никогда не коммитятся.

## Где переменные каждой части

| Часть | Префикс | Полная таблица |
|------|---------|----------------|
| `shipwide_api` | (серверный env) | [Бэкенд](/ru/shipwide/backend) + `src/config/env.ts` (валидируемый источник истины) |
| `shipwide_app` | `VITE_` | [Приложение](/ru/shipwide/app) + `src/vite-env.d.ts` |
| `shipwide_admin` | `VITE_` | [Админка](/ru/shipwide/admin) |
| `shipwide_website` | `PUBLIC_` | [Сайт](/ru/shipwide/website) |

## Минимум для старта бэкенда

`DATABASE_URL`, `REDIS_URL`, `JWT_SECRET` (≥32 символов). Всё остальное (Google/Apple, SMTP,
RevenueCat, OneSignal, admin) опционально и инертно до настройки — ненастроенная интеграция
возвращает понятную ошибку, а не падает при старте.

## Межчастные связки, которые должны совпадать

- **Приложение/сайт → база API**: `VITE_BACKEND_URL` (приложение), `PUBLIC_SUPPORT_ENDPOINT` (форма
  поддержки сайта). Пустой backend URL на сайте = форма поддержки в demo-режиме.
- **Origin админки ↔ CORS API**: задайте `ADMIN_URL` в env API на origin админки, иначе CORS
  откажет (выглядит как баг авторизации). Нативные схемы разрешены всегда.
- **`CORS_ORIGINS`** (API) должен точно перечислять каждый веб-origin (веб-сборка приложения, сайт).
- **`client_id`**: приложение `VITE_CLIENT_ID` (по умолчанию `app`), админка `admin` — просто метка сессии.

## Подводные камни

<Warning>
  **OneSignal:** приложение знает только `VITE_ONESIGNAL_APP_ID` (публичный). REST-**ключ API — это
  серверный секрет** в `shipwide_api`; никогда не переносите его в `VITE_*`.
</Warning>

- **`VITE_APP_NAME`** неймспейсит *все* локальные данные приложения (шифрованное хранилище,
  настройки, кэш, deep-link-схема). Смена после запуска осиротит существующие локальные данные.
- **Добавляйте любую новую `VITE_*` в `src/vite-env.d.ts`** — из-за индексной сигнатуры
  `vite/client` опечатка не ошибка типа, а просто `undefined`.
