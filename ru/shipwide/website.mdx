Маркетинговый сайт для одного приложения: быстрый сайт с индивидуальным дизайном на **Astro**
(статическая сборка), **рукописной дизайн-системой на SCSS** (без UI-фреймворка),
**astro-i18next** для переводов и **Iconify** для иконок. Портала аккаунтов нет — это публичный
маркетинг. Всё поставляется как плейсхолдеры: подставьте бренд, тексты и ассеты — и вперёд.

## Быстрый старт

```bash
npm install
npm run switch_to_dev   # env/env.dev → .env
npm run serve           # http://localhost:4321
# продакшен:
npm run switch_to_prod  # env/env.prod → .env (сначала задайте домен)
npm run build           # astro-i18next generate + astro check + astro build → статика
```

## Где что лежит

| Путь | Что это |
|------|---------|
| `src/data/site.ts` | Имя бренда, email, соцсети, навигация. **Правьте первым.** |
| `src/data/product.ts` | Продукт: каналы загрузки, тарифы, возможности, скриншоты. |
| `src/screenshots/*.png` | Галерея на главной — именуйте `01-…`, `02-…` для порядка. Удалите демо. |
| `src/data/legal.ts` | Структура документов Privacy / Terms. |
| `public/locales/en/*.json` | Весь читаемый текст, по файлу на неймспейс. |
| `src/content/blog/*.md` · `changelog/*.md` | Посты блога / релиз-ноуты — по Markdown-файлу. |
| `src/styles/` | Дизайн-система на SCSS (токены, база, компоненты, утилиты). |

<Note>
  **Правило:** языко-нейтральные факты (URL, цены, ники) живут в `src/data/`; всё, что читатель
  видит словами, — в `public/locales/`.
</Note>

## Ребрендинг (короткий путь)

<Steps>
  <Step title="Данные бренда и продукта">
    Правьте `src/data/site.ts` (`name`, email, соцсети — имя бренда в шапке/подвале/заголовках
    управляется целиком `site.name`) и `src/data/product.ts` (ссылки загрузки, цены, возможности).
  </Step>
  <Step title="Ассеты">
    Замените `public/favicon.svg` (опционально добавьте `public/og-default.png`); положите свои
    скриншоты в `src/screenshots/` (`01-…`, `02-…`) и удалите демо.
  </Step>
  <Step title="Домен и тексты">
    Задайте `PUBLIC_SITE_URL` в `env/env.prod`; замените тексты в `public/locales/en/*.json`.
  </Step>
</Steps>

## Токены дизайна и шрифты

Цвета, шрифты, радиусы, отступы, тени и движение — CSS-переменные в `src/styles/_variables.scss`,
со светлой и тёмной темами:

- **Акцент** — рампа dusty-indigo (`--accent-50…900`); меняйте `--accent-400` (тёмная) /
  `--accent-600` (светлая) — распространится везде.
- **Нейтральные** — тёплые серые, не чистый цинк.
- **Шрифты — пара:** дисплейный **Golos Text**, самохостинг через `@fontsource/golos-text`, на
  заголовках (`--font-display`), и системный стек для тела/UI. Подойдёт любой OFL-шрифт с кириллицей.

## Языки

Поставляется **английский + русский**; переключатель в шапке. Добавление третьего языка — пять
шагов (коды в `astro-i18next.config.ts`, `astro.config.mjs`, `Header.astro` + `nav.json`, копия
`public/locales/en/` → `<code>/` и перевод, затем `npm run build`). Только английский: уберите
`"ru"` из трёх списков и удалите `public/locales/ru/`.

<Warning>
  `src/pages/ru/` **генерируется** `astro-i18next generate` при сборке и в gitignore — правьте
  английский источник; русское дерево регенерируется.
</Warning>

## Контент, форма поддержки, мониторинг

- **Блог и changelog** — контент-коллекции Astro: добавили Markdown — появилось.
- **Форма поддержки:** задайте `PUBLIC_SUPPORT_ENDPOINT` на эндпоинт бэкенда, чтобы она постила.
  Пусто (по умолчанию) = demo-режим (уведомление «напишите нам»), без постинга.
- **Sentry** грузится только при заданном `PUBLIC_SENTRY_DSN`, принятых куках и не на `localhost`.
