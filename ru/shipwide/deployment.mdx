<Warning>
  **Золотое правило: секреты остаются на сервере.** Впишите плейсхолдеры `CHANGE-ME` в `env.prod`
  API прямо там, никогда не коммитьте их и никогда не кладите секрет в `VITE_*` / `PUBLIC_*` (они
  вшиваются в поставляемый бандл).
</Warning>

## Бэкенд (`shipwide_api`)

- **Docker**: контейнер стартует `migrate → seed → serve`. Миграции + идемпотентный сид запускаются
  автоматически. Дайте управляемые Postgres 17 + Redis 7 (или поднимите рядом).
- **Purge cron** (обязательно): запускайте ежедневно — `node dist/jobs/purge.js` (скомпилированный
  путь; `tsx` только для dev). Это физическая половина удаления аккаунта + ретеншена тикетов;
  идемпотентно.
- **Почта**: направьте `SMTP_*` на транзакционного провайдера (например Postmark). Настройте **SPF,
  DKIM, DMARC** на домене-отправителе — при беспарольной авторизации код в спаме = никто не войдёт.
- **CORS**: `CORS_ORIGINS` = ваши точные веб-origin(ы). Нативные схемы (`capacitor://localhost`,
  `tauri://localhost`) и `ADMIN_URL` админки разрешены всегда.
- **Секреты**: `DATABASE_URL`, `REDIS_URL`, `JWT_SECRET` (≥32), `SMTP_*`, `ADMIN_*` и любая
  включённая интеграция `GOOGLE_/APPLE_/REVENUECAT/ONESIGNAL`.

## Приложение (`shipwide_app`)

- **Веб / PWA**: `npm run build` → статика (сохраняет предсжатые `.gz`/`.br`). Раздавайте с любого
  статик-хоста / CDN. Его origin должен быть в `CORS_ORIGINS` API.
- **iOS / Android**: `npm run build:native` (ставит `SHIPWIDE_NATIVE=1`, чтобы сжатые ассеты не
  попадали в WebView), затем откройте закоммиченные проекты `ios/` / `android/` в Xcode / Android
  Studio для архивации и отправки.
- **Десктоп**: Tauri собирает из `src-tauri/` (Rust stable). Иконки через `npx tauri icon`.

## Админка (`shipwide_admin`)

Docker + nginx, собирается с `--build-arg VITE_*`:

```bash
docker build --build-arg VITE_API_URL=https://api.example.com \
             --build-arg VITE_SITE_URL=https://example.com \
             --build-arg VITE_BRAND="Your product" -t shipwide-admin .
docker run -p 8080:80 shipwide-admin
```

nginx раздаёт SPA (откат на `index.html`, хешированные ассеты кэш навсегда / `index.html` — никогда,
`noindex` + `DENY`). Вне образа: (1) укажите `ADMIN_URL` в env API на этот origin, иначе CORS
откажет; (2) поставьте **сетевой барьер** спереди (Cloudflare Access / IP-allowlist) — она читает
данные всех и не нуждается в публичной доступности.

## Сайт (`shipwide_website`)

`npm run switch_to_prod` (сначала задайте домен), затем `npm run build`
(`astro-i18next generate + astro check + astro build`) → статика; раздавайте с любого статик-хоста /
CDN. `PUBLIC_*` вшиваются при сборке. Если форма поддержки постит в ваш API, задайте
`PUBLIC_SUPPORT_ENDPOINT` и добавьте origin сайта в `CORS_ORIGINS` API.
