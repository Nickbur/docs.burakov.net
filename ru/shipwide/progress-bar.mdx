Shipwide поставляет тонкую полосу прогресса внизу экрана, визуализирующую загрузку страницы — как
на YouTube или GitHub. Работает из коробки на каждой странице и платформе (Web/PWA, iOS, Android,
Desktop) с **нулевой настройкой на страницу** в обычном случае и простым opt-in для страниц,
грузящих свои данные.

## Как это работает

**Один общий инстанс полосы** — на экране никогда не больше одной полосы:

1. **Автоматически (router-driven).** Роутер показывает полосу при навигации, заметнее всего в вебе,
   где заход на маршрут скачивает его lazy-чанк. Каждая страница получает это бесплатно.
2. **Opt-in (page-driven).** Страница, грузящая свои данные, ведёт ту же полосу через загрузку,
   чтобы полоса отражала реальную загрузку.

Эти два **взаимоисключающи на маршрут**, что гарантирует одну неконфликтующую полосу.

- **Trickle:** `start()` показывает полосу и даёт ей ползти к 90% самостоятельно; `done()` доводит
  до 100% и прячет. Выглядит живой, даже когда длительность неизвестна.
- **Задержка показа (200 мс):** навигации быстрее этого не мигают полосой. В нативных сборках чанки
  маршрутов забандлены, поэтому навигация мгновенна и полоса роутера просто не появляется.
- **Доступность:** уважает `prefers-reduced-motion` — переход заливки и анимированные точки выключаются.

## Быстрый старт: ничего делать не нужно

Для обычной страницы, которая просто рендерится (без загрузки данных при входе), **ничего не
делайте** — полоса роутера уже покрывает её. Это каждая статическая страница в наборе.

## Добавление страницы с загрузкой данных

<Steps>
  <Step title="Пометьте маршрут">
    В `src/router/routes.ts`, чтобы роутер передал полосу странице, а не завершал её при заходе:

    ```ts
    {
      path: '/reports',
      component: () => import('@/views/pages/reports/Reports.vue'),
      meta: { requiresAuth: true, managesProgress: true },
    }
    ```
  </Step>
  <Step title="Ведите её — всегда завершайте в finally">
    ```ts
    import { useRouteProgress } from '@/composables/useRouteProgress';
    const pageProgress = useRouteProgress();

    onMounted(async () => {
      pageProgress.start();          // показать + авто-trickle
      try {
        await loadReports();
      } finally {
        pageProgress.done();         // ВСЕГДА завершать, даже при ошибке
      }
    });
    ```
  </Step>
  <Step title="(Опционально) многошаговый">
    Зовите `set()` между этапами для детерминированной полосы (это останавливает авто-trickle):

    ```ts
    pageProgress.start();
    await loadHeader();  pageProgress.set(0.4);
    await loadRows();    pageProgress.set(0.8);
    await loadFooter();  pageProgress.done();
    ```
  </Step>
</Steps>

<Tip>
  Канонические примеры в наборе: `Subscription.vue`, `Support.vue`, `Onboarding.vue` подключены
  ровно так — копируйте с них.
</Tip>

## API — `useRouteProgress()`

Глобальная полоса, используемая в 99% случаев. Все вызовы целятся в один общий инстанс.

| Член | Описание |
|------|----------|
| `progress` | `Ref<number>` `0..1`; `1` = простой/скрыто. |
| `start()` | Показать полосу и дать ей автоматически ползти до `done()`. |
| `set(p, b?)` | Прыгнуть к явному значению; **останавливает** trickle (теперь ведёте вы). |
| `done()` | Довести до 100% и скрыть. Безопасно звать многократно. |

Для полосы, которая должна быть отдельной от глобальной (например внутри модалки), используйте
низкоуровневый ключевой `useSharedPageProgress(key)` или `useCombinedPageProgress(...keys)`, чтобы
ждать несколько источников.

## Практики

- **Всегда `done()` в `finally`.** Если загрузка бросит, а вы не завершите — полоса останется видимой.
- **Не помечайте статические страницы `managesProgress`.** Поставите флаг и не позовёте `done()` — полоса зависнет.
- **Предпочитайте глобальную полосу.** Две полосы в глобальной позиции перекрылись бы.
- **`start()` vs `set()`:** `start()` = «не знаю сколько, покажи активность»; `set()` = «знаю реальный процент».

## Кастомизация

Всё в `useRouteProgress.ts` и `styles/components/page-progress-bar.scss`:

| Что поменять | Где |
|--------------|-----|
| Цвет | `--progress-background` в scss |
| Толщина | `height` в scss (по умолчанию `3px`) |
| Вертикальная позиция | `bottom` в scss (замените на `top`, чтобы прижать под статус-бар) |
| Задержка показа | `SHOW_DELAY_MS` в composable (по умолчанию `200`) |
| Скорость / потолок trickle | `TRICKLE_INTERVAL_MS` (260) / `TRICKLE_CEILING` (0.9) |
