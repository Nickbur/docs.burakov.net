Shipwide — это **мультиплатформенный стартовый набор**: общая основа, извлечённая из реальных
продакшен-приложений и упакованная как переиспользуемая. Это точка старта, на которой вы строите
свой продукт, а не готовое приложение. **Четыре части, один продукт:**

| Часть | Что это | Стек |
|------|---------|------|
| `shipwide_api` | Бэкенд — аккаунты, авторизация, сессии, подписки, поддержка, загрузки, admin API | Fastify + Drizzle + PostgreSQL + Redis (Node 22+) |
| `shipwide_app` | Клиент — одна кодовая база для веба, iOS, Android, десктопа | Vue 3 + Ionic + Capacitor + Tauri |
| `shipwide_admin` | Панель оператора — управление одним развёртыванием | Vue 3 SPA |
| `shipwide_website` | Маркетинговый сайт | Astro (статика) + SCSS |

## Строительные блоки, а не готовое приложение

Это ментальная модель, которая делает набор понятным:

- **Каждая экспортируемая часть — готовый к использованию строительный блок**: обработчик бэкенда,
  Vue-composable, функция api-клиента, компонент. То, что *сейчас* не подключено к маршруту или
  странице, — не мёртвый код; оно ждёт, пока вы его используете.
- **Заглушки экранов сделаны намеренно** — экраны аккаунта / сессий / настроек в приложении это
  стабы. Набор даёт вам «водопровод»; экраны продукта вы строите поверх.
- **Удаляйте код только если** он реально сломан, это настоящий дубликат логики из другого места
  или нарушение архитектуры — а не просто потому что «его пока никто не вызывает».

<Note>
  Источник истины — всегда код. Эти доки описывают набор, который поставляется; когда важна деталь,
  последнее слово за реализацией.
</Note>
