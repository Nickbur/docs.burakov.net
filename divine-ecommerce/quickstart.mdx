Divine eCommerce runs entirely in Docker, driven by a `Makefile`. You need **Docker with Docker Compose** and
**Git** — PHP, PostgreSQL and Node all run in containers.

## Install

<Steps>
    <Step title="Clone and configure">
        ```bash
        git clone https://github.com/Nickbur/divine-ecommerce.git
        cd divine-ecommerce
        cp env/env.dev .env
        ```
        `npm run switch_to_dev` does the same copy. See [Configuration](/divine-ecommerce/configuration) for every key.
    </Step>
    <Step title="Start the stack">
        ```bash
        make up
        ```
        This starts nginx, PHP-FPM, PostgreSQL, Redis and the background worker (`cron`). Until the next two steps are
        done, the worker logs errors — that's expected.
    </Step>
    <Step title="Install dependencies and build assets">
        ```bash
        make composer-install
        make npm-install && make npm-build
        ```
        `npm-build` type-checks, lints and checks formatting before it builds, so it fails on unformatted code.
    </Step>
    <Step title="Create the database and load demo data">
        ```bash
        make migrate && make seed
        ```
        `make seed` loads roles, demo accounts, categories, brands, products with options and cross-variants,
        specifications, bundles and store settings, then builds the filter and search indexes.
    </Step>
    <Step title="Open the store">
        Storefront: [http://localhost:8090](http://localhost:8090) · Admin: [http://localhost:8090/admin](http://localhost:8090/admin)
    </Step>
</Steps>

## Local ports

| Service | Host port | Set by |
| --- | --- | --- |
| Store (nginx) | `8090` | `APP_PORT` |
| PostgreSQL | `5434` | `DB_EXTERNAL_PORT` |
| Redis | `6381` | `REDIS_EXTERNAL_PORT` |
| Adminer (only with `make up-all`) | `8888` | `ADMINER_PORT` |

## Full demo data

`make seed` doesn't load blog articles, info pages, menus or reviews, and there are **no sample orders**. To load
every seeder, including content:

```bash
docker compose exec php vendor/bin/phinx seed:run
make reindex-facets
```

<Warning>
    Seeding is **destructive**: several seeders empty their tables first, and that cascades into orders and products.
    Only seed a database you're happy to wipe.
</Warning>

## Everyday commands

```bash
make up            # start the stack
make down          # stop it
make up-all        # also start Adminer and the asset watcher
make npm-dev       # watch and rebuild front-end assets
make migrate-fresh # roll back everything, migrate and reseed
make check         # DB-write guard + PHPStan + PHPUnit
make cache-clear   # clear compiled templates and caches
make help          # list every target
```

The full list is in [Commands & scheduled jobs](/divine-ecommerce/commands).
