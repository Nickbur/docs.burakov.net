Configuration lives in one `.env` file at the project root, copied from `env/env.dev` (local) or `env/env.prod`
(production) — `npm run switch_to_dev` / `npm run switch_to_prod`, or `cp`. Both templates list the same keys in the
same order. Docker Compose passes `.env` to the PHP and worker containers; images never include it.

## Application

| Variable | Template value (dev / prod) | Effect |
| --- | --- | --- |
| `APP_ENV` | `dev` / `prod` | `prod`: **Secure** session cookie (HTTPS required), compiled DI container, errors hidden. `dev`: links in emails use `APP_URL`. Anything other than `dev`: links in emails use **Settings → Branding → Store Website**. |
| `APP_DEBUG` | `true` / `false` | Detailed error pages, Kint dumps and the Clockwork profiler. **Always `false` in production.** |
| `APP_PORT` | `8090` / `80` | Host port nginx is published on. |
| `APP_URL` | local URL / your domain | Base for email links in `dev` only, and for LiqPay's return page (`/checkout/success`) and payment confirmation (`/checkout/liqpay/callback`). In production, set it to your public **HTTPS** address. |

## Database and services

| Variable | Default | Effect |
| --- | --- | --- |
| `DB_DRIVER` | `pdo_pgsql` | Doctrine DBAL driver. PostgreSQL is the only supported database. |
| `DB_HOST` | `postgres` | The Compose service name. |
| `DB_PORT` | `5432` | Port inside the Docker network. |
| `DB_NAME`, `DB_USER`, `DB_PASS` | `divine`, `divine`, — | Database name and credentials. Use a strong password in production. |
| `DB_EXTERNAL_PORT` | `5434` (dev) | Host port for PostgreSQL. Not published in production. |
| `REDIS_EXTERNAL_PORT` | `6381` (dev) | Host port for Redis. Not published in production; the app doesn't use Redis yet. |
| `ADMINER_PORT` | `8888` | Adminer, started only by `make up-all` (the `tools` profile). |

## Templates

| Variable | Default | Effect |
| --- | --- | --- |
| `TWIG_AUTOESCAPE` | `html` | Twig's escaping strategy. Templates are written for `html` — keep it in every environment, and run `make cache-clear` if you change it. |
| `TWIG_AUTO_RELOAD` | `true` / `false` | Recompile templates when they change. |
| `TWIG_STRICT_VARIABLES` | `false` | Fail on undefined template variables. |
| `TWIG_OPTIMIZATIONS` | `-1` | Twig optimizer flags (`-1` = all). |

## Mail

| Variable | Effect |
| --- | --- |
| `SMTP_HOST`, `SMTP_PORT` | Your SMTP server. The templates ship `REPLACE_ME` placeholders and port `587`. |
| `SMTP_USER`, `SMTP_PASS` | SMTP credentials. |
| `SMTP_ENCRYPTION` | `ssl` for implicit TLS (usually port 465); anything else uses plain SMTP upgraded with STARTTLS when the server offers it. |
| `MAIL_FROM_ADDRESS`, `MAIL_FROM_NAME` | The sender of every email. Use an address on your own domain. |

No local mail catcher is included. For local testing, point `SMTP_*` at a test inbox service, or run your own catcher
and set `SMTP_HOST` to it.

## Other keys

| Variable | Effect |
| --- | --- |
| `LIQPAY_PUBLIC_KEY`, `LIQPAY_PRIVATE_KEY` | Your LiqPay keys. With both set and the LiqPay method active in **Settings → Payments**, checkout offers online card payment — see [Online payment](/divine-ecommerce/checkout-and-orders#online-payment-liqpay). |
| `CLOCKWORK_API`, `CLOCKWORK_TOOLBAR` | Present in the templates but not read by the code — the profiler follows `APP_DEBUG`. |

<Warning>
    Keep production secrets in the server's `.env` only — it's ignored by git. Never commit real keys to a public
    fork.
</Warning>

## Admin settings that take effect

Store settings live in the database and are edited in **Settings**. These tabs change the storefront:

| Tab | Live keys |
| --- | --- |
| General | Site name (also used in email subjects and page titles), site description |
| Contacts | Main phone and email (contact-form messages are sent to this email), phones, working hours, address, city, country, social links, map embed |
| Branding | Logo, copyright text, **Store Website** (base of email links outside `dev`) |
| Marketing | Promo banner on/off and text |

Everything on the **Store**, **Checkout**, **Locale**, **Tax** and **Loyalty** tabs — and the favicon — is
stored but not used yet. Store-wide SEO, including the page-title template, is set in
**Tools → Search Engine Optimization** — see [SEO & analytics](/divine-ecommerce/seo). Taxes and reward points are
configured in **Settings → Taxes** and **Sales & Marketing → Loyalty points**. Delivery and payment methods have
their own sections, **Settings → Delivery** and **Settings → Payments**.
