by default. Contributions are accepted **by invitation only**.

## Building (for invited contributors)

The build runs in Docker, so the host needs only a few tools:

| Tool | Why |
| --- | --- |
| Docker | Runs the build container (Ubuntu with the Rust nightly toolchain, the three targets, xorriso and cargo-deny). |
| Node.js 24.16 or later | Runs the project scripts; older versions are refused. |
| QEMU, `qemu-img`, `mkfs.fat` | Boot the result and create a test disk. |

```bash
npm install
npm run os:build
```

`os:build` checks formatting, then builds every architecture inside the container. Before building it runs the
**dependency licence and advisory check** (`cargo deny`) and a publishability check — the build fails if either does.
Images land in `build-result/` as `omos-<arch>.iso`.

## Running and debugging

| Script | Does |
| --- | --- |
| `npm run run:iso:mac` / `run:iso:lin` / `run:iso:win` | Create the test disk if needed and boot the x86_64 image in QEMU (Windows via WSL). |
| `npm run debug:iso:mac` / `debug:iso:lin` / `debug:iso:win` | Boot paused, waiting for a debugger on GDB's default port (`1234`). |
| `npm run verify` / `npm run deny` | Run the pre-build checks on their own. |
| `npm run fix` | Reformat the repository. |
| `npm run clean` | Remove build output. |
