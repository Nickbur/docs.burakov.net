OMOS ships as a bootable **UEFI ISO image**, `omos-x86_64.iso`. The way to try it is in **QEMU**, a free virtual
machine — nothing on your computer changes.

<Note>
    Images aren't published for download yet. When they are, they'll be linked from the
    [OMOS page](https://burakov.net/projects/omos). The steps below apply to the ISO once you have it.
</Note>

## What you need

| | |
| --- | --- |
| **QEMU** | `qemu-system-x86_64` |
| **UEFI firmware for QEMU** | OVMF. Linux and WSL: the `ovmf` package, at `/usr/share/ovmf/OVMF.fd`. macOS (Homebrew QEMU): `$(brew --prefix)/share/qemu/edk2-x86_64-code.fd`. |
| **Optional, for a virtual disk** | `qemu-img` and `mkfs.fat` (dosfstools) |

OMOS boots only with UEFI firmware — legacy BIOS boot isn't supported.

## Boot it

<Steps>
    <Step title="Optional: create a FAT32 disk">
        ```bash
        qemu-img create -f raw disk.img 64M
        mkfs.fat -F 32 disk.img
        ```
        OMOS mounts it at boot. Skip this step and remove the two disk lines from the command below if you don't need
        it.
    </Step>
    <Step title="Start QEMU">
        On Linux or WSL:
        ```bash
        qemu-system-x86_64 \
          -drive if=pflash,format=raw,readonly=on,file=/usr/share/ovmf/OVMF.fd \
          -cdrom omos-x86_64.iso \
          -drive file=disk.img,format=raw,if=none,id=disk0 \
          -device virtio-blk-pci,drive=disk0 \
          -device virtio-keyboard-pci \
          -m 256M -smp 4 \
          -serial stdio -no-reboot -no-shutdown
        ```
        On macOS, replace the firmware path with `$(brew --prefix)/share/qemu/edk2-x86_64-code.fd`.
    </Step>
    <Step title="Watch it boot">
        The QEMU window shows the OMOS status screen; your terminal shows the serial log. See
        [What you see at boot](/omos/first-boot).
    </Step>
</Steps>

| Option | Why |
| --- | --- |
| `-drive if=pflash,…` | Loads the UEFI firmware. |
| `-device virtio-blk-pci` | Attaches the FAT32 disk through a virtio block device — the only disk type OMOS's filesystem uses today. |
| `-device virtio-keyboard-pci` | A virtio keyboard; key events appear in the serial log. |
| `-m 256M -smp 4` | 256 MB of memory and 4 CPU cores. |
| `-serial stdio` | Sends the serial log to your terminal. |
| `-no-reboot -no-shutdown` | Keeps the window open if the system halts, so you can read the last messages. |

Close the QEMU window, or press **Ctrl+C** in the terminal, to stop it.

## Real hardware

There's **no installer** and no supported way to run OMOS on a physical machine yet. A spare x86_64 PC with UEFI
might boot the ISO from a USB stick, but this isn't tested or supported — use a virtual machine.

## ARM64 and RISC-V

These architectures run only in QEMU's `virt` machine during development, and no images are provided for them. See
[Platform support](/omos/platform-support).
