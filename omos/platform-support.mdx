| | x86_64 | ARM64 (AArch64) | RISC-V 64 |
| --- | --- | --- | --- |
| **Status** | Developer preview | Development only | Development only |
| **Where it runs** | QEMU with UEFI (OVMF) | QEMU `virt` machine | QEMU `virt` machine |
| **Real hardware** | Not supported yet | Not supported | Not supported |
| **Image** | `omos-x86_64.iso` | Not provided | Not provided |
| **Firmware** | UEFI | UEFI | UEFI |

ARM64 and RISC-V support is written for QEMU's `virt` machine: the addresses of the serial port, interrupt
controller and timer frequency are fixed to that machine's layout, so these builds won't run on physical boards.

## Device support

| | x86_64 | ARM64 | RISC-V |
| --- | --- | --- | --- |
| **Serial** (log output only) | COM1 | PL011 | 16550 |
| **Display** | Text on the firmware's framebuffer (GOP) | Same, if the firmware provides a framebuffer | Same, if the firmware provides a framebuffer |
| **Interrupts** | 8259 PIC, then I/O APIC | GICv3 | PLIC |
| **Timer** | Local APIC (PIT-calibrated) | Generic Timer | SBI timer |
| **Keyboard** | PS/2 and virtio-input | virtio-input | virtio-input |
| **Storage** | virtio-blk, NVMe, AHCI (FAT32 on virtio-blk only) | Same | Same |
| **Performance/efficiency cores** | Detected (Intel hybrid) | Detected | Treated as identical |
| **Network, audio, GPU, USB** | — | — | — |

The serial port carries the system log; it doesn't accept input.

## Requirements

- **UEFI firmware** — legacy BIOS boot isn't supported.
- **Memory** — the QEMU set-up uses 256 MB.
- **CPU cores** — one is enough; additional cores are started automatically.

See the [Quickstart](/omos/quickstart) to boot the x86_64 image.
