## Today

OMOS can't send anything anywhere — it has **no networking** at all: no network drivers, no network stack, no
internet connection of any kind.

| | |
| --- | --- |
| **Telemetry** | None. There's no usage measurement and nothing to opt out of. |
| **Account** | None. There's no sign-in or registration. |
| **Updates** | No update mechanism — nothing is downloaded or installed in the background. |
| **Ads** | None. |
| **Activation** | None in the system today. |

What OMOS writes is limited to the serial log on your own machine and, if you attach one, the FAT32 disk in your
virtual machine.

## The licence

The [EULA](/omos/licensing) states that OMOS is designed to work offline with no telemetry by default. If a future
version adds anything online — activation, royalty administration or optional services — how personal data is handled
is described in the Privacy Policy on [burakov.net](https://burakov.net).

## Building OMOS

Only the **build** process uses the internet, on the developer's machine — to fetch the Rust toolchain, crates and
security advisories, and the bootloader. The resulting image doesn't contact anything.
