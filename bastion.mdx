Bastion is a **self-hostable, end-to-end encrypted** communication platform for organizations. Run it on your own server — or let it be managed for you — invite your team, and get **encrypted chat and calls** on every device. Your messages, files and calls stay on infrastructure you control.

## Two audiences, one product

Bastion is built for two people:

- **Members** use the apps — chat, calls and files — on web, desktop, iOS and Android.
- **Operators** deploy and run the node, and manage the organization from a separate admin panel.

Start with the section that fits you: [Chat](/bastion/chat) and [Calls](/bastion/calls) if you're a member, [Self-hosting](/bastion/self-hosting) and [Administration](/bastion/administration) if you're running it.

<Note>
  Bastion's base module is **chat + calls**. It's modular by design, so more capabilities can be enabled for an organization over time.
</Note>
